# 阶跃星辰 Harness v1.0.10

- **发送反馈更快**：打开旧会话时提前恢复底座，冷启动直接加载原历史，避免重复加载。发送的消息立即显示在对话区；失败会恢复草稿，并保护等待期间的新输入。
- **消息下方的分叉入口已接通**：从完成的回复创建独立会话，保留之前的上下文与附件，并自动切换过去。原会话和工作区文件不受影响；新增重复点击保护、失败提示与历史锚点校验。
- **确认一次，后续自动更新**：全新的星辰确认弹窗，适配中英文及浅深色。确认后自动下载、校验、静默安装并重新打开；任务运行时等待任务结束。
- **开场说明遵从简答要求**：明确要求“只回答、仅需回答”时跳过开场钩子，不额外生成开场请求。

Windows 安装包：**StepFun-Harness-1.0.10-win-x64.exe**。

自动更新的新流程在安装本版后生效；从旧版升级到本版时，仍使用旧版已有的确认流程。

## English

- **Faster send feedback:** restore existing sessions when opened and load their native history directly on cold start. Submitted messages appear immediately; failures restore the draft without overwriting newer typing.
- **Fork from a reply:** the existing message action now creates and selects an independent conversation with the preceding context and attachments. The parent conversation and workspace files stay intact, with duplicate-click protection and validated history anchors.
- **One confirmation, automatic updates:** a new branded dialog supports English, Chinese, light and dark themes. After confirmation, download, verification, silent installation and reopening proceed automatically, waiting for active tasks to finish.
- **Respect concise-answer requests:** explicit requests to provide only the answer bypass the opening hook and its additional opening request.

Windows installer: **StepFun-Harness-1.0.10-win-x64.exe**.

The new update flow applies after installing this version. Upgrading from an older version still follows that version's existing confirmation flow.
