# 阶跃星辰 Harness v1.0.11

这一版集中打通 Windows 原生工具、文件修改与撤销、附件分叉和实时输出，让实际执行与界面展示保持一致。

- **原生 PowerShell**：启用底座已有的 Windows 工具，保留原生审批、超时与取消机制，改善中文路径和 PowerShell 变量处理。
- **工具状态更准确**：审批、等待执行、正在执行、主动停止各自对应真实状态；文件修改预览支持原生查找替换和删除。
- **差异与撤销更可靠**：分散修改按实际行数统计；同一文件的大小写路径正确归并；未完成检查点不虚构删除，无变化文件不误挡其他文件撤销。
- **附件修改不再被覆盖**：重复准备和历史同步保留已编辑的副本；新分叉继承附件当前内容，相关历史路径同步迁移到子会话。
- **后台队列更稳**：没有界面订阅时仍保存编辑、删除和排序结果；及时回收已结束的调度记录。
- **长输出更轻便**：实时更新只发送新增文本，相同内容不重复刷新；截断的命令结果可打开完整日志，搜索结果保留截断与超时标记。

Windows x64 安装包：**StepFun-Harness-1.0.11-win-x64.exe**。已有用户可在应用更新界面升级，或直接下载安装包。数据与设置保留，Step 底座随 Harness 统一发布。

---

## English

This release improves the connection between native Windows tools, file editing and undo, attachment forks, and live output.

- Enable native PowerShell with existing approval, timeout, and cancellation handling.
- Show accurate tool execution states and native search-and-replace previews.
- Improve change counts, path identity, checkpoint handling, and safe file undo.
- Preserve edited attachments during history synchronization; give new forks independent working copies and consistent history paths.
- Persist queue changes even without an active UI subscription, and release finished dispatch records.
- Stream only new tool output, skip duplicate updates, expose full command logs, and retain search truncation/timeout status.

Windows x64 installer: **StepFun-Harness-1.0.11-win-x64.exe**. Upgrade through the app or download the installer. User data and settings are preserved. The Step runtime remains bundled with Harness releases.
