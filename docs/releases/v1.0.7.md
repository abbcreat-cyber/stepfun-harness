# 阶跃星辰 Harness v1.0.7

这次更新让文件、任务和工作流之间的衔接更可靠。

- **文件改了，预览跟着更新**：文本、代码、图片、PDF、Word 和幻灯片预览自动反映文件变化。文本刷新保留阅读位置，文件删除后重建也能恢复显示。
- **搜索更及时**：新增文件可立即找到，改名和删除后清理旧命中；补齐历史会话正文索引。
- **工作流沿用项目模型**：从保存的工作流卡片启动时，正确使用项目配置的模型。
- **交互提问支持多选**：模型可以明确发起多选问题，配合自由输入完成问答。
- **撤销与文件链接更稳妥**：修复开场说明钩子对文件检查点的影响，处理 Windows 短暂文件占用，保留外部修改冲突检查；修正包含中文、空格、井号和百分号的本地链接。
- **统一软件更新**：底座由维护者适配并验证后随 Harness 整包发布，软件内只保留一个简洁的更新入口；修复自动化在正常退出时的运行状态清理。

已用 Step Plan 订阅完成真实小任务验收，覆盖队列中断与恢复、多图及混合附件、问答、文件预览和导出、幻灯片局部编辑、浏览器表单与导航失败恢复。

Windows 用户下载 **StepFun-Harness-1.0.7-win-x64.exe**，运行安装即可；已有用户也可在软件内检查更新。

## English

This release improves how files, tasks, and workflows work together.

- **Live file previews**: text, code, images, PDFs, Word documents, and presentations refresh when their source changes. Text refreshes retain the reading position, and recreated files become visible again.
- **Fresher search**: discover new files immediately, remove stale results after renames or deletions, and backfill historical conversation text indexes.
- **Configured workflow models**: launching a saved workflow uses the model configured for its project.
- **Multiple-choice questions**: models can explicitly request multiple selections alongside free-text answers.
- **Safer undo and reliable file links**: fix opening-hook checkpoint interference and handle brief Windows file locks while preserving external-edit conflict checks. Correct local links containing Unicode, spaces, hash signs, and literal percent escapes.
- **One software update channel**: runtime updates are integrated and validated by the maintainer before shipping with Harness. The app now has one update entry. Automation shutdown also releases its active run state correctly.

Validated with real, bounded Step Plan tasks covering queue interruption and recovery, images and mixed attachments, interactive questions, previews and exports, selected-slide editing, browser forms, and recovery from navigation failures.

On Windows, download and run **StepFun-Harness-1.0.7-win-x64.exe**, or check for updates in the app.
