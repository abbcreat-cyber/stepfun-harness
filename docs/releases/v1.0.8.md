# 阶跃星辰 Harness v1.0.8

这次更新着重减少等待，让任务、浏览器和文档之间的操作更顺畅。

- **新任务预热更高效**：修复切回新任务时，空会话刚启动又被回收重建的问题。4 个任务的实测中，底座启动次数从 8 次降到 4 次。
- **任务列表减少重复读取**：列表没有变化时，不再反复读取全部聊天正文；查询单个任务时，只读取目标任务。历史积累较多时能减少本地磁盘与解析开销。
- **浏览器准备更简洁**：合并首次只读信息获取，减少不必要的模型与工具往返，同时保留目标检查和权限规则。
- **文档图片和链接正确打开**：Markdown 的相对图片与文件链接按文档所在目录解析，兼容中文、空格等路径。

本轮还完成了真实小任务回归，覆盖粘贴图片、附件数量限制、长文本、文件撤销、文档恢复、Git 提交范围、任务切换与重命名。底座和模型思考配置保持不变。

Windows 用户下载 **StepFun-Harness-1.0.8-win-x64.exe** 安装；已有用户可在软件内检查更新。

## English

This release reduces unnecessary work when starting tasks, using the browser, and navigating documents.

- **More efficient task prewarming**: fix a draft session being started, discarded, and recreated when returning to a new task. In a four-task check, runtime starts dropped from eight to four.
- **Fewer repeated history reads**: unchanged task-list refreshes no longer reread every conversation. Queries for a specific task read only that task, reducing local disk and parsing work as history grows.
- **Simpler browser startup**: combine initial read-only observations to reduce model/tool round trips while retaining target checks and permission rules.
- **Working document images and links**: resolve Markdown images and local links relative to the document, including paths with Unicode and spaces.

Real small-task regression checks also covered pasted images, attachment limits, long text, file undo, document recovery, Git commit scope, task switching, and renaming. The bundled runtime and model reasoning settings are unchanged.

Download **StepFun-Harness-1.0.8-win-x64.exe** on Windows, or check for updates in the app.
