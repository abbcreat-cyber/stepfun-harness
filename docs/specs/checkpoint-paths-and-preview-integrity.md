# 文件快照身份和差异统计

文件操作仍由原生工具执行，桌面扩展只记录前后快照。撤销保持当前哈希、连续快照链、重叠修改及符号链接检查。

1. 新快照使用文件系统 realpath 返回的实际路径归并同一文件。已存在文件在执行前规范化，新建文件在执行后规范化；不存在的路径保持原值。禁止单凭 Windows 平台把全部路径转小写，避免合并大小写敏感目录中的不同文件。旧历史不猜测修补。
2. 修改统计只对前后内容快照完整的文件计算；缺少内容时保留无法验证/无法撤销的提示，但不把未知内容当成空文件统计整文件删除。新增、删除和无变化仍通过明确的 missing/null 快照判断。
3. 差异预览在等价匹配方案中优先输出删除行，再输出新增行，保持上下文与可重建性，不改变实际写入内容。

验收覆盖同文件路径大小写变化后的两次顺序修改和撤销、外部修改冲突、缺少快照、真实删除、替换差异和重复行；使用订阅小任务生成真实快照，再在隔离测试文件上预览并撤销。仅更新本机及本地 Git，不上传云端。
