# 已发送消息编辑、回复重试与文件回退

状态所有者：Step 原生 session tree 独占聊天历史；session worker 独占命令准入和 UI 投影；原生扩展在文件工具执行前后记录 checkpoint，自定义 entry 不进入模型上下文。

```text
桌面命令 → worker 输入串行链 → 校验 epoch/revision/稳定实体/空闲
                               → Step fork → 更新原生文件引用 → 统一发送入口
文件工具 → before/after checkpoint → 原生持久 entries → 回退预览 → 哈希复核 → 文件恢复
```

- 编辑和重试只接受最新真实用户轮，运行、队列和工作流活动时拒绝；不默默丢弃后续已接受输入。重试复用原附件、文本；编辑未传附件保留原附件，显式空数组删除。
- 使用原生 fork 回到该 user message 之前，在原桌面会话内重新执行；旧原生分支保留。成功后必须保存新 sessionFile，重载不得返回旧分支。原生取消或失败不能改 UI 历史。
- 消息实体绑定经原生 entry 校验后开放动作。删除投影后 rowId 仍单调不复用；旧实体、旧 epoch/revision 拒绝。命令幂等沿用现有 ACK 台账。
- 文件回退只恢复目标用户轮的 write_file/edit_file 等明确文件工具；shell 操作如实忽略，不粗暴还原整个工作区。缺少快照的旧历史不能伪造回退能力。
- checkpoint 保存文件前镜像与后哈希；限制普通文件大小，拒绝 symlink、重叠写和不连续哈希链的回退。执行前再次核对全部文件，外部变化阻止覆盖。执行失败保留恢复材料且返回失败；不能报告全部成功。
- preserve 编辑不操作文件；rewind 编辑先安全回退再分支。文件回退单独执行不截断聊天。若原生分支失败，文件恢复动作须回滚；发送失败保留已经建立的新分支并明确失败，禁止假恢复旧聊天。
- 桌面连续和远端重放均消费相同权威 snapshot，不新增 renderer 业务状态。先落盘再公布成功。

验收：真实订阅小任务编辑、重试、文件写入回退、冲突拒绝和重载；本地测试覆盖取消/原生失败、附件、旧 target、运行/队列拒绝、中文空格路径、新建文件、修改文件、重叠工具与外部修改。
