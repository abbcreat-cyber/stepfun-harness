# 内部插件依赖的展示边界

真实插件市场测试发现 `node-repl-host` 被展示为用户插件，尽管其官方说明明确它只是浏览器等能力共享的内部宿主。

- 插件适配层 scan 是用户可见列表的唯一来源：list、overview、referenceCatalog 共用过滤结果。
- 仅过滤官方 `node-repl-host`；同名自定义插件仍可管理。
- 不删除依赖文件，不改变安装、插件签名、MCP 注册或浏览器启停逻辑；内部宿主仍由官方能力管理。
- 用户无法通过插件管理入口单独停用该内部依赖，避免出现无实际独立能力的开关。
- 验收：三类目录均不展示内部宿主；文件仍在；浏览器插件停用、重载、启用后可真实执行。
