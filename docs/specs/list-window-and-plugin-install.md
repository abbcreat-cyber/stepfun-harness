# 列表窗口与插件安装的读取优化

## 行为

- `session/list` 的 limit 在读取正文前生效：身份/墓碑/ID 筛选后，若候选摘要的 lastActivityAt 均为有限非零数字，按现有稳定降序取前 limit 项，再读取这些正文。若有缺失、零值或非有限时间戳，保留原先全部读取、投影默认时间、排序截断的兼容路径。完整索引快照不截断。
- 插件安装复用启用操作之后已经完成的扫描结果来生成 installedPlugins，不再第三次扫描。安装前检查、锁内校验、修改声明和安装后扫描顺序不变；公开 setEnabled 仍只返回 plugin/enabled；overview 的外部参数不得被当作可信扫描结果。
- 两处都不增加跨请求缓存。后续读取仍能看到文件、模型配置和插件状态变化。底座、权限及模型调用不变。

## 所有者

会话索引拥有摘要筛选/排序，conversation store 拥有正文；既有 session/list 投影拥有模型/权限输出。插件 handler 拥有本次安装和对应临时扫描结果，锁仍由 withStepPluginState 管理。

```mermaid
flowchart LR
  A[插件安装] --> B[安装前扫描]
  B --> C[持锁校验并修改声明]
  C --> D[安装后扫描]
  D --> E[生成启用结果与安装列表]
```

## 验收

实际 QA 索引对比有限列表的读取数、结果顺序和局部耗时；测试相同时间的稳定顺序、非法时间回退及模型/权限元数据。插件测试计数独立插件的扫描读取次数，覆盖 dryRun、安装后启用状态、公开返回形状、后续刷新与失败路径。用订阅小任务验证任务切换/列表与浏览器插件工作；只更新本机和本地 Git。
