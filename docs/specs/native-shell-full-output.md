# 原生命令完整输出

底座 shell 工具负责执行、截断及完整日志文件。适配层把原生 details.truncation.truncated/fullOutputPath 映射到已有 bash_output 展示协议，保留正文；不通过输出文案猜文件、不重新执行命令、不另存一份日志。

只接受 shell 工具的明确布尔截断标记和合法绝对路径。普通短结果不添加提示；相对路径或 URL 不变成文件入口。原始 output.truncated 仍保留为桌面按需读取引用，不混用。

前端在展开命令时说明输出已截短，并提供“查看完整输出”，通过原有文件预览打开原生日志。历史行保存文件引用，不承诺临时日志永久存在；缺失文件沿用文件预览错误显示。操作不得再次请求模型或运行命令。

验收覆盖短输出、长输出、错误/缺失元数据及路径边界；真实底座生成超过 2000 行输出，检查日志首尾，订阅实测并在后台点击查看完整输出。仅本地部署和 Git 提交。
