# 正文搜索与自动化退出结算

历史迁移：workspace 首次索引基线在后台以最多 4 路读取缺少正文的既有会话，仅用 existing-only runtime。补写仍由 TaskIndexRepo 串行写入，只在 updatedAt 未变且正文仍为空时生效；不改标题、排序、未读、归档及运行状态，不广播历史完成。读取失败保留原状态。恢复会话及调整模型/思考档位返回的兼容快照同样保留正文，避免后续再次清空索引。

1. Step 会话 V4 rows 是可见聊天唯一来源。session/read 需从这些 rows 派生兼容 messages，供现有 Host task-index writer 索引；不能返回空 messages 清空 searchable_text。只包含真实用户正文和每轮最后的可见回复，排除 reasoning、tool、隐藏运行提醒。使用稳定 row identity，最多 200000 字符。编辑/重试切分支后只索引当前 rows；创建时间保持原值。
2. 手动自动化的运行 claim 由派发 Host 持有。正常退出时先停止续租和订阅，等待服务/运行时关闭，再结算该 Host 仍持有的本地运行为 stopped 并释放 manual claim，最后关闭数据库。不能清空其他 Host 的任务或远端仍在执行的任务；服务关闭失败/超时时保留原崩溃回收机制。意外杀进程仍由已有十分钟 stale claim 机制处理。

```text
V4 rows → session/read 派生消息 → 现有 task-index → 正文搜索
Host quit → 停止本 Host 订阅/续租 → 关闭运行时 → 结算持有的本地运行 → 关闭 repo
```

验收：正文唯一标记搜索命中；隐藏工具/思考不进入搜索；改写分支后旧正文不再出现。自动化等待权限时正常退出，重开可立即再次手动运行，实际生成文件；暂停计划保持暂停，运行次数与历史真实保留。其他测试继续覆盖标题搜索、历史定位、中文文件搜索、Word/PPT 渲染。本轮仅本地提交和部署。
