# 工具预览的内容与状态边界

工具状态来自底座，前端只解释已收到的结果，不通过内容猜测执行成功或失败。

- 成功读取/写入的空串与空白串都是有效内容，不应回退成缺少预览或其它结果。
- 普通读取的内容即使包含 diff 标记也按文件文本展示；显式结构化差异与编辑类工具继续走差异预览。
- 已成功读取的位图路径使用图片预览，附带的说明文字不取代图片。SVG 文本仍可作为源代码展示。
- 成功返回中的普通 message、文件正文中的 tool_use_error 标签不是执行失败。明确 error 字段和底座 failed 状态仍保留错误解释；failed 输出文字不得当作文件内容展示。
- 读取工具的等待审批/待调度/运行/停止状态与其他原生工具一致，停止后不持续显示正在读取。

复用 codeViewer、toolError 及统一工具阶段解析；不改磁盘内容、底座工具和协议。不改变读取卡片“打开当前文件”的既有含义。

验收：空白内容、diff 正文、位图与 SVG、成功消息及标签、真实失败与停止；订阅小任务读取测试文件/图片，并在后台打开文件预览。只更新本地软件与 Git，不发布云端。
