# 工作流片段等待与终态

工作流桥接拥有确认请求；片段服务拥有本次调用的取消信号。片段 deadline 从确认前开始，覆盖确认和执行。完全访问模式的片段命令沿用会话授权，计划模式拒绝，普通模式仍展示确认。创建持久工作流的确认不变。

```text
MCP 调用 → 工具行准入 → 片段调用信号 → 确认 → 沙箱执行 → 结果
                           ↑           ↓
                 停止 / 截止 / 断连 → 清除等待
工具终态 → 撤销该工具的确认；旧确认不能复活工具
新会话 worker 冷读 → 无执行者的历史行标为中断 → 同一桌面/远端快照
```

工具失败后删除 interactionId；迟到批准不得把失败状态改为 running。终态清理包含 pendingApproval。冷恢复只处理该 session worker 的非活动普通历史，不改变只读子代理投影，不凭历史 running 重放命令；保留原始结果，已记录工具错误恢复为 error，其余未决项标记取消。结束计时使用最后已有事件时间，不把离线时间冒充工作时间。

验收：命令片段在完全访问下直接完成；普通模式允许/拒绝有效；未答确认在 deadline 内返回并清除；工具超时后迟到批准无效；停止等待/执行均收口；进程冷恢复旧 pending/running 不再无限计时；真实 Step Plan 小任务跑通命令片段。
