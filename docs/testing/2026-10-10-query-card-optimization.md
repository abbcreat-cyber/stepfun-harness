# 搜索输入调度与文件卡片校验验收

本轮修改前端搜索 hook、卡片验证及文件服务的可选即时校验参数，不改底座或模型配置。

## 行为验证

- 真实 React hook 的受控延迟测试：A未完成时输入B、C，旧实现已发出3个RPC；新实现保持1个在途，A收口后只查询C，共2个RPC。旧输入不会覆盖新结果，不用固定延时防抖。
- 搜索错误现在属于当前结果；继续输入可重新检索。工作区切换不等待旧作用域，过期结果被忽略，无命中仍按原规则补扫一次。
- 文件服务测试先缓存“不存在”，创建文件后显式refresh立即返回true；先缓存“存在”再删除，refresh返回false。卡片验证请求携带refresh并去重路径，网页卡片不做文件检查，15项上限保持。
- 默认存在性缓存及其原调用行为保留；仅显式即时校验绕过缓存和旧在途请求，不写回启发式缓存。
