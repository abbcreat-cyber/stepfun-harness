# 默认文件候选与 PDF 读取优化验收

本轮涉及共享 Host 文件搜索服务和前端 PDF 读取，不改底座或模型配置。

## 对照

- 20 万个受控候选、空查询取前 80 项：原算法五轮为 25.72/16.77/10.88/13.68/9.56ms，新算法为 0.23/0.02/0.01/0.01/0.01ms。仅是 Host 已构建候选的选择耗时，不包含文件索引构建、文件存在性核验和 UI 渲染。
- 自动回归比较文件优先/同类稳定顺序，并计数确认足够文件后停止访问索引。非空搜索沿用原打分算法。
- 小 PDF 改为直接填充最终缓冲，不再累计全部分块再整体复制。保持 2MiB 全读阈值和 256KiB 分块；回归复现并修正了文件增长时末块越过初始大小，以及提前取消仍调用一次读取的问题。EOF、短读、读取异常与取消后的结果保持有界。

- 5 项针对回归通过，覆盖候选顺序与限额、改名/删除/类型变化、PDF 完整字节/短读/EOF/取消/异常。
- 一条旧搜索测试假设只命中文件；D盘测试根的绝对路径可合法模糊匹配到父目录。将断言聚焦文件迁移及旧路径不残留，未修改非空搜索规则。
