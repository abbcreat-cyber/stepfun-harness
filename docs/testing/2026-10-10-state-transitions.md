发现并修复：

1. 内部 Node Repl Host 出现在用户插件列表。统一在适配层过滤官方内部宿主；运行文件及依赖装配保持可用，同名自定义插件可继续管理。
2. 主代理已经通过 GetWorkflowRun 发现并回答的问题，排队提醒随后仍被投递，导致工作结束后再检查、再解释一次。通知改为保存问题引用，在准入和队列投递前查询权威等待状态；失效提醒取消，后续用户消息继续调度。
3. 接着复测还发现相同的重复完成通知。对于主代理已经通过成功 GetWorkflowRun 回执读到的 completed 结果，取消排队的重复提醒；未读取的完成结果和错误通知仍保留。判定直接使用持久化工具回执，不维护第二份已读状态。

测试驱动校正：市场菜单负责安装，启停位于“管理已安装”；重载后需要重新进入设置。插件 mention 转换成编辑器节点后，等待输入应按任务标记核对，不能要求 DOM 保留原始 Markdown 链接。相关失败记录保留在本机，不计为额外产品故障。

相关自动回归共 71 项通过、2 项因未设置外部 CLI 测试变量跳过；通知回归已拆入独立 workflow-notices 套件，保留完整测试入口。类型检查和架构检查通过，lint 为 0 error、77 warning。
