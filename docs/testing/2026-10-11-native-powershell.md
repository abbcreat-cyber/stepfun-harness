# Windows 原生 PowerShell 验收

## 根因与修复范围

核对故障会话的 20 条命令：原生工具 arguments 与前端 input 全部一致，其中 4 条执行报错。变量和反斜杠由外层 Git Bash 解释，嵌套 PowerShell 输出还存在代码页问题，并非前端或传输层删改命令。

随包 Step 0.1.3 已有原生 powershell 工具，但未纳入默认活动工具集。本次通过桌面扩展激活该能力，调整模型工具说明，并接入前端 shell 分类和文件检查点副作用边界；未修改 Step 可执行文件。

## 验证结果

- 20 项定向测试通过：原生变量、中文、路径、权限拒绝、非零退出、超时和取消，以及开场说明、权限策略、历史控制回归。
- 类型检查通过；Lint 为 0 errors、77 warnings；架构检查 0 violations；生产构建通过。
- Step Plan 订阅模型 step-5-preview 在隔离桌面实例完成一次只读快捷方式查询，耗时约 23 秒。两次 powershell 调用均成功，保留变量、中文、空格路径；未回退 run_command，未写临时脚本。
- 前端工具身份测试确认 powershell 归一化为 PowerShell，复用 shell 展示类型。
- 本机替换构建及适配模块，校验文件哈希后后台重启，保留窗口可见状态且不抢焦点。

以上覆盖本次已知跨 shell 故障及相关控制边界，不代表任意 PowerShell 脚本或所有模型均已实测。本次只更新本机和本地 Git，不发布云端。
